一款專為《遊戲王 Master Duel》開發的自動化資產解析、圖檔替換、超框卡圖 (Over-Frame Art) 渲染，以及虛擬模組管理工具。本專案基於 Python 3、PySide6 與 UnityPy 構建，致力於解決遊戲資產修改過程中的繁瑣步驟與底層檔案結構問題。

## 核心技術與演算法說明

本工具在底層解析與系統資源管理上，實作了以下技術與演算法，以確保穩定性與自動化能力：

### 1. 二進位 XOR 混淆解密與自動猜解引擎
遊戲內的文字資料庫 (如 card_name.bytes) 採用了自訂的 XOR 混淆加密。本工具實作了對應的解密演算法，公式為 `(i + key + 0x23D) * key ^ (i % 7)`。
為了解決遊戲版本更新可能導致密鑰 (Key) 變更的問題，系統內建了自動爆破機制 (`auto_crack_key`)。當預設密鑰失效時，程式會在 0 到 1023 的範圍內進行迭代，並利用 zlib 解壓縮的成功與否來驗證密鑰的正確性，使工具具備自我修復能力，無須因為密鑰更換而頻繁更新工具版本。

### 2. IL2CPP Metadata 逆向映射與 CRC32 校驗
遊戲內的配件檔案 (如卡套、場地、頭像) 通常缺乏明文 ID，僅以 Hash 命名。為了解析這些資源的真實名稱，工具會讀取遊戲的 `global-metadata.dat`，利用正規表達式提取 `ID([0-9]{6,7})`，隨後對這些字串 (如 `IDS_ITEM.ID{id}`) 計算 CRC32 哈希值。最後，將計算出的哈希值與透過 msgpack 解析 `ids_item.bytes` 得到的字典進行交叉比對，精準還原所有非卡片物件的中文名稱。

### 3. 卡片屬性特徵碼與靈擺雙軌判定 (Dual-Check)
在解析 `card_prop.bytes` 時，程式會以 8-bytes 為一個區塊進行位元運算。透過讀取特定位元組，判定 0x020D 為魔法卡，0x024E 為陷阱卡；怪獸卡則提取並使用 6-bit 遮罩 (`b2 & 0x3F`) 來判定子類型 (例如融合、同步、超量)。
由於靈擺卡片在底層的二進位標記較為複雜，工具實作了雙軌判定機制。系統會同時檢查「卡片效果文是否包含靈擺關鍵字」與「二進位特徵碼是否吻合」，兩者取 OR 邏輯，徹底解決靈擺卡片分類遺漏的問題。

### 4. Unity Bundle 記憶體安全直接注入
在「模組串流修復」功能中，為了將舊模組的圖片轉移到新版遊戲檔案中，工具避開了傳統的完整解包與重新打包流程 (這通常會導致極大的記憶體消耗)。
程式直接讀取目標 Texture2D 物件，將新原檔的 `m_StreamData` 屬性 (包含 path, offset, size) 強制歸零，藉此截斷外部串流，接著將舊模組的 raw bytes 直接寫入 `image_data`。此內嵌 (Inline) 注入技術能有效防止 OOM (Out of Memory) 崩潰，並確保檔案相容性。

### 5. 超框註冊表二進位重構
遊戲透過 `of_card_asset` 檔案來判定哪些卡片應該套用超框 (Over-Frame) 渲染。工具將該檔案作為 TextAsset 讀取，並將其內部的二進位資料以 uint16 (`<HH`) 結構解包為 `[Trigger_ID, Target_ID]` 的陣列。
使用者透過介面輸入新的 ID 後，程式會進行衝突檢查 (過濾官方佔位符與自訂衝突)，並將新的陣列重新打包寫回 Bundle。系統同時會建立 `.pristine` 純淨基準檔，防止多次寫入導致原始檔案結構損壞。

### 6. PSD 多圖層動態合成與快取引擎
處理超框卡圖時，工具整合了 psd-tools 函式庫，動態讀取 PSD 模板並精準抽離 PeriFrame、NameBox、ArtFrame、EffFrame、EffBox 五個獨立圖層。
為了應對批次處理數百張圖片的效能瓶頸，工具實作了 `_psd_cache` 記憶體快取。使用者可以透過設定介面自訂這五個圖層的透明度 (0~100%)，程式會利用 PIL 的 Alpha 通道運算即時合成。若執行環境缺少對應套件，程式會觸發 Fallback 機制，自動降級使用靜態 PNG 模板。

### 7. 系統級交易回滾與 Vanilla 備份機制
虛擬模組管理器採用 Windows 符號連結 (Symlink) 進行模組掛載，達到零硬碟空間佔用的效果。
在替換遊戲原檔前，程式會將原始檔案重新命名為 `.vanilla_backup` 進行保護。掛載過程實作了原子化交易回滾 (Transaction Rollback) 機制，只要迴圈中發生任何權限不足或檔案佔用錯誤，系統會立即中斷掛載，並根據 `state_log` 紀錄將所有已更動的檔案復原，確保遊戲本體絕對安全。

### 8. 作業系統級記憶體防護與動態路徑剪枝
在爆搜遊戲目錄時，為了避免低配電腦卡死，程式調用了 Windows `GlobalMemoryStatusEx` API 來監控系統實體記憶體。當記憶體負載超過 85% 時，執行緒會自動進入休眠等待釋放。
此外，針對 `os.walk` 實作了 `prune_walk_dirs` 動態剪枝演算法。透過在走訪前預先剔除輸出目錄與暫存目錄，有效阻斷無限遞迴與不必要的硬碟 I/O。

### 9. AST 抽象語法樹與多語系動態萃取
為了降低多語系維護成本，工具捨棄了手動維護翻譯字典的做法。程式會呼叫 Python 內建的 `ast` 模組，將主程式解析為抽象語法樹，並走訪所有的 `ast.Call` 與 `ast.keyword` 節點，精準萃取出被 `_("...")` 包覆的字串以及 UI 佔位符。
萃取後，程式會自動與現有的 `zh-tw.json` 進行比對，保留已翻譯的內容並增量補齊新字串，實現高度自動化的國際化 (i18n) 維護。

### 10. EXE 打包虛擬化 (MockModule)
在使用 PyInstaller 打包為獨立執行檔時，遊戲引擎原生的音效依賴 (如 fmod) 常會因為缺少 DLL 而導致程式啟動崩潰。
為了在不需要音效的環境下順利編譯，程式頂部定義了繼承自 `types.ModuleType` 的 `MockModule`，透過攔截 `__getattr__`，在 `sys.modules` 中對 `fmod_toolkit` 與 `pyfmodex` 進行虛擬化替換。此作法大幅提高了程式碼的可攜性與打包成功率。

### 11. 自訂線性拖曳捲動過濾器
為了解決 Qt 內建的 QListWidget 拖曳捲動手感生硬、且帶有無法關閉的物理慣性震盪問題，專案內實作了 `LinearDragScrollFilter` 事件過濾器。
透過攔截滑鼠移動事件，程式引入了小數點像素累積器 (Scroll Accumulator)，將不到 1 像素的微小捲動量先儲存，累積滿整數後再呼叫 QScrollBar 進行步進。這使得 UI 拖曳體驗達到了如同現代網頁瀏覽器般滑順且即停即止的標準。

## 模組與分頁功能詳細說明

專案介面分為 14 個獨立分頁，各自分工處理 Mod 製作管線中的不同環節：

* **0. 新手指南**：提供整體工具的操作流程、概念說明以及各分頁的功能摘要。
* **1. 爆搜與補齊**：透過多進程 (ProcessPoolExecutor) 掃描遊戲目錄的 0000 資料夾。解密文字檔後，生成包含檔案 Hash 碼、卡片 ID、名稱、效果與屬性的對照表 (CSV 格式)，作為後續所有操作的資料基底。
* **2. 找出檔案**：讀取生成的 CSV 對照表，支援文字與正規表達式搜尋。使用者可以選取欲修改的卡片，系統會自動比對並將對應的 Hash 檔案從遊戲目錄中複製到專案工作區。
* **3. 提取資料**：利用 UnityPy 載入上一步挑選的檔案，走訪物件樹尋找 Texture2D 資源。提取過程中會自動比對圖片解析度，過濾掉低畫質的縮圖，匯出乾淨的原卡圖並保留原始檔案備份。
* **4. 更改卡圖**：處理將外部修改好的圖片重新封裝回 Bundle 的作業。程式會讀取圖片並使用 Lanczos 演算法進行高品質縮放，對齊原始 Texture2D 的長寬後進行二進位替換並存檔。
* **5. 封裝模組**：自動判讀卡片所在的目錄類型 (常規 0000 或是 StreamingAssets)，在輸出目錄中自動重建對應的資料夾結構，並支援一鍵壓縮為 ZIP 檔，方便分享與安裝。
* **6. 智慧串連執行**：提供自動化工廠排程，可將「找出檔案、提取資料、後處理、更改卡圖、封裝模組」這五個步驟串接。依賴回呼函數 (Callback) 序列，只要確保輸入路徑正確，即可一鍵完成所有繁瑣流程。
* **7. 靈擺與超框卡圖後處理**：專為進階卡面美化設計。支援將靈擺卡圖進行下方透明像素填充以防遊戲內變形；以及支援 11:16 比例裁切與 PSD 五圖層動態合成，將一般卡圖轉化為超框立體卡圖，並提供 QImage 即時預覽面板。
* **8. 快捷單卡改圖**：簡化完整專案建立的步驟。輸入卡片 ID 與圖片路徑後，程式會直接提取、修改並覆寫遊戲原檔。此功能包含特殊路由，支援直接對 `data.unity3d` 等裸檔進行修改 (如替換大廳背景)。
* **9. 超框卡片註冊器**：專門讀寫 `of_card_asset` 註冊表。提供現有名單解析、外部註冊表合併與衝突檢查功能。將欲修改的卡片 ID 寫入白名單後，遊戲便會對該卡片套用無邊框與超框渲染邏輯。
* **10. 圖形化瀏覽器**：提供場地、頭像、卡套等視覺資產的圖庫檢視。程式會將磁碟 I/O 轉換為記憶體查表，快速生成網格縮圖。支援沙盒篩選模式，並能將選取的項目一鍵傳送至提取清單或快捷改圖介面。
* **11. 模組串流修復器**：因應遊戲更新導致 Mod 失效的救援工具。透過分析新版遊戲原檔，直接將舊模組中的貼圖串流資料無損移植寫入，省去重新製作模組的龐大時間成本。
* **12. 虛擬模組管理器**：透過建立系統符號連結 (Symlink)，讓模組生效而不需要複製龐大的檔案。提供左右清單拖曳調整優先權的功能，並具備嚴格的權限判定與安全回滾機制，方便玩家快速切換多個模組進行測試。
* **13. 設定與外觀**：集中管理工具的全域環境變數與外觀。支援自訂五維度調色盤 (動態套用 QSS)、更換背景圖片與九宮格對齊錨點、調整多進程算力上限，以及匯出 AST 解析的翻譯樣板。
